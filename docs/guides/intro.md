These guides offer ways to leverage Konifer's vast feature set to solve common problems and use cases. They
are a work in progress and more will be added. Feel free to suggest a guide by logging an issue in the
[Konifer repository](https://github.com/dmaiken/konifer/issues).

## What you will need

These guides require:

1. **Docker or OCI-compatible runtime:** Konifer is deployed exclusively as a Docker image. Any OCI-compatible runtime
   such as [Podman](https://podman.io/) should work, but guides assume Docker is being used.
2. **Bruno:** An open source Postman equivalent. [Installation](https://docs.usebruno.com/get-started/bruno-basics/download)
   is easy and does not require an account.

## Open the Bruno collection

Download or clone the [Konifer documentation repository](https://github.com/dmaiken/konifer-docs), then select
**Open Collection** in Bruno and choose the repository's `docs/bruno` directory. Requests that accompany a guide are
grouped under the **Guides** folder.
