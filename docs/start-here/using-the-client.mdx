The Konifer client wraps the HTTP API for Kotlin and Java. Version `{{koniferClientVersion}}` supports JVM 17 or newer;
Kotlin/Native and JavaScript targets are not part of this release.

## Install the client

Add Maven Central to your project's repositories and include the client dependency.

Gradle:

```kotlin
implementation("io.konifer:konifer-client:{{koniferClientVersion}}")
```

For a Java project using Gradle, use `io.konifer:konifer-client-jvm:{{koniferClientVersion}}`.

Maven:

```xml
<dependency>
  <groupId>io.konifer</groupId>
  <artifactId>konifer-client-jvm</artifactId>
  <version>{{koniferClientVersion}}</version>
</dependency>
```

## Choose your client

Use `KoniferClient` for suspending Kotlin calls or `KoniferBlockingClient` for blocking Java/JVM calls. Both expose
the same operations and return `KoniferResult<T>`.

Build the client with your server's base URL, without `/assets`. Reuse it across requests and close it at application
shutdown.

## Store an image and get its URL

Start the [Quickstart](getting-started.md#1-start-konifer) server at `http://localhost:8080`. Run this example from the
documentation repository, or replace `static/img/konifer-small.png` with your own PNG.

<Tabs groupId="konifer-example-language" defaultValue="kotlin">
<TabItem value="kotlin" label="Kotlin (suspending)">

```kotlin
import io.konifer.client.KoniferClient
import io.konifer.common.image.ImageFormat
import java.nio.file.Files
import java.nio.file.Path

suspend fun main() {
  val client = KoniferClient.build("http://localhost:8080")
  try {
    val assets = client.assets("users/123/profile-picture")
    val image = Files.readAllBytes(Path.of("static/img/konifer-small.png"))

    val asset = assets.newAsset()
      .fromBytes(image, ImageFormat.PNG)
      .withAlt("Konifer logo")
      .store()
      .valueOrThrow()

    val link = assets.entry(asset.entryId)
      .originalVariant()
      .fetchLink()
      .valueOrThrow()

    println("Stored entry: ${asset.entryId}")
    println(link.url)
  } finally {
    client.close()
  }
}
```

</TabItem>
<TabItem value="java" label="Java (blocking)">

Save this program as `Example.java`.

```java
import io.konifer.client.KoniferBlockingClient;
import io.konifer.common.image.ImageFormat;
import java.nio.file.Files;
import java.nio.file.Path;

public class Example {
  public static void main(String[] args) throws Exception {
    try (var client = KoniferBlockingClient.build("http://localhost:8080")) {
      var assets = client.assets("users/123/profile-picture");
      var image = Files.readAllBytes(Path.of("static/img/konifer-small.png"));

      var asset = assets.newAsset()
        .fromBytes(image, ImageFormat.PNG)
        .withAlt("Konifer logo")
        .store()
        .valueOrThrow();

      var link = assets.entry(asset.getEntryId())
        .originalVariant()
        .fetchLink()
        .valueOrThrow();

      System.out.println(link.getUrl());
    }
  }
}
```

</TabItem>
</Tabs>

Open the printed URL to view the stored image. The server's delivery configuration determines whether it points to
Konifer, object storage, or a CDN.

## Handle results

Call `valueOrThrow()` to get the successful value or throw `KoniferRequestException` on failure. To recover from a
request failure, inspect the `KoniferResult` instead: `Failure.Http` includes the HTTP status, while
`Failure.Transport` and `Failure.InvalidResponse` include the underlying cause. Coroutine cancellation propagates as
an exception.

## Optional configuration

Pass `hmacKey` and the matching signing algorithm to `build()` if your server requires
[signed retrieval URLs](../reference/url-signing.md). Use `KoniferHttpConfiguration` to set request, connection, and
socket timeouts.
